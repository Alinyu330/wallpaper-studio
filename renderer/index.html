桌面快捷方式

同屏显示数量

收纳方式
移动到收纳目录：文件真正离开桌面进入程序目录，关闭程序 / 卸载后可一键恢复；恢复后图标位置由资源管理器重排，不保证原位。
隐藏到壁纸后：文件留在原地，仅把图标停到屏幕外（肉眼不可见、无法点选 / 框选）；恢复后精确回到原位；依赖资源管理器列表视图，其重启或「自动排列」可能复位（有看门狗自动重新隐藏）。
系统图标（回收站 / 此电脑等）没有实体文件，恒走隐藏方式。
排列方向

调整位置

九宫格定位
点击快速摆放到常用位置；「默认」恢复任务栏上方居中，拖动调整仍可用

转盘用法：按住图标条或下方「拖动条」左右拖动即可像转盘一样轮换图标，滚轮同样可轮换；需要移动整个转盘时，点上方「调整位置」按钮后按住拖到任意位置；右键转盘可添加/移除快捷方式。

快捷方式列表

「一键收纳全部」会收走桌面上所有快捷方式（.lnk / .url，含文件名与显示名不一致的）与程序文件（.exe / .bat / .cmd）。系统图标（此电脑 / 回收站等）不是文件、桌面文件夹与办公文档是用户数据，均不移动（可到「文件收纳」页单独收纳）；「公共桌面」（所有用户可见）的快捷方式需要管理员权限，收纳后可点上方按钮一次授权批量收进。

「点选/框选收纳」打开全屏选择器，手动勾选要收纳的桌面快捷方式；收纳后从转盘点击图标照常启动对应 App；从列表移除或「全部恢复到桌面」即还原到原位置；关闭快捷方式转盘功能也会自动全部还原。

收纳文件的存放位置将在启动后显示。

收纳文件的存放位置将在启动后显示。

已收纳的文件 / 文件夹

「一键收纳」会收走桌面上所有普通文件（办公文档 / 媒体 / 归档等）与文件夹；快捷方式与程序文件仍归「快捷方式」转盘收纳。文件夹仅登记收纳（不移动内容），点开进入文件夹；普通文件会移动到应用数据目录保管，移除或「全部恢复」即还原到原位置。
